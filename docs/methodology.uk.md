# Як зібрано цей набір

🇬🇧 [Read in English](methodology.md) · [← README](../README.uk.md)

Числа заміряно на завершеному бекфілі, 2026-08-02. Кожне з них походить із
`wantedmt volume` і самого стану, а не з нотаток, — тому його можна перерахувати
після будь-якого прогону, замість того щоб воно застаріло в прозі.

---

## Серія

Портал зберігає по одній ревізії на кожне вивантаження, і дістатись до них можна
через `resource_show` → `resource_revisions`. Саме це робить історію можливою
взагалі: початкове ТЗ виходило з того, що ресурс перезаписується на місці, а
минуле запису можна лише накопичувати наперед.

| | |
| --- | --- |
| Ревізій у серії | 1_825 |
| Покривають | 2019-07-15 … 2026-08-01 (2_574 дні) |
| Згорнуто | 1_776 — 1_700 від МВС, 76 від НПУ |
| Розпізнано як перепубліковані байти | 41 |
| Відхилено як «це не реєстр» | 7 |
| Провалено | 1 (2021-08-30) |
| Файлів, що потребували структурного ремонту | 290 |

## Вага: опубліковано, перекачано, збережено

Три різні питання і три різні відповіді. Назвати будь-яку з них «розміром
набору» було б неправильно — щоразу по-своєму.

| | |
| --- | --- |
| Опубліковано порталом | **536.05 ГБ** |
| Завантажено | 522.98 ГБ |
| Не качали — хеш уже був відомий | 12.60 ГБ |
| **Збережено на диску** | **0.49 ГБ** |
| Збережено ÷ опубліковано | **0.092%** |

Збережене — це 160 МБ стану і 334 МБ parquet-журналу змін. Похідний набір
приблизно в тисячу разів легший за сім років вихідних файлів, і будь-який
минулий день усе одно відновлюється з журналу змін, нічого не качаючи.

Прочитано рядків: 1_844_634_671. З них 10_963_346 відкинуто як `id`, що
повторюються всередині одного файла, — це дублювання видавця, і воно пораховане,
а не відкинуте мовчки: саме кількість є єдиною ознакою, що файл зібрали двічі.

## Що додає історія

| | |
| --- | --- |
| Записів бачено взагалі | **1_186_719** |
| Присутні в поточній публікації | 1_062_497 |
| **Закриті — зникли з реєстру** | **124_222** |
| Зникли й повернулись | 21_514 |

124_222 закритих записи — і є сенс усієї вправи. Їх немає у файлі, який портал
віддає сьогодні, тож без цієї історії про них не можна сказати нічого: ні що
вони існували, ні коли припинили. Ще 21_514 записів пішли й повернулись; із
самого лише поточного файла вони виглядають як рядки, що ніколи не рухались.

## Дати — це відліки, а не події

Кожна дата життєвого циклу тут — це дата, коли реєстр **прочитали**. Запис
з'явився десь між попереднім відліком і тим, що вперше його показав, а відстань
між ними не завжди дорівнює одному дню:

| | |
| --- | --- |
| Спостережень — днів, коли реєстр справді читали | 1_773 |
| Найдовший розрив між двома спостереженнями | 190 днів |
| Знімків записано, але не довірено закривати записи | 52 |

Перепубліковані байти навмисно виключені з календаря спостережень. Між
2020-09-28 і 2021-03-29 портал ще дев'ятнадцять разів віддав файл від
2020-09-22; зараховані як відліки, вони казали б, що реєстр перевіряли всю зиму
і він не рухався.

Тому кожен запис несе ширину власної невизначеності — `first_seen_days`,
`disappeared_days`, — і NULL там означає «необмежено», а не «нуль». Місячний ряд
несе `is_measured` з тієї ж причини: місяць без жодного відліку звітує, що його
не міряли, а не що крадіжок не було.

## Що відхилено і чому

Нічого не викинуто мовчки. Кожне виключення записано в `snapshots` разом із
причиною, і числа вище складаються рівно в 1_825 ревізій.

- **7 — це не реєстр.** П'ять дат 2020 року несуть єдину ревізію на 3 байти;
  2019-07-15 несе 891 КБ проти нормальних 293 МБ; 2021-10-21 приходить
  байт-у-байт таким, як обіцяє лістинг, і містить 556_969 записів проти реєстру
  на 1_028_000. Вони записані як пропущені, а не як провалені: повторювати спробу
  над зіпсованою публікацією означає вічно спинятись на тому самому файлі.
- **41 перепублікація.** Розпізнані за хешем із самого лістингу, тому не коштували
  жодного завантаження.
- **1 провал.** 2021-08-30 втрачено через помилку блокування файла під час
  ремонту, і його свідомо залишено так: знімки — це повні вивантаження, тож
  згорнути його після того, як прогін пішов далі, означало б переписати
  сьогодення, а не заповнити прогалину. Календар спостережень просто не містить
  того дня.
- **52 підозрілі знімки.** Записані повністю, разом із тим, скільки записів
  бракувало, але їм не дозволено нічого закривати. Серед них — перехід МВС→НПУ:
  зміна відомства не є доказом, що мільйон телефонів знайшли.

## Персональні дані

По всій серії знайдено 418_636 телефонних номерів абонентів; вони лежать у
`quarantine_personal` — таблиці, з якої публікована вітрина не будується. Де
саме вони ховаються, описано в [source_defects.uk.md](source_defects.uk.md):
ім'я поля оголошує їх лише в одній із трьох форм, яких набуває DTL.

У публікованій вітрині немає колонки, що могла б їх утримати, і блокуюча
перевірка стверджує це проти `information_schema`, а не проти запиту, який
хтось має не забути написати.
